# Проверка анализа на одном артикуле

Для сравнения взят HUAWEI MateBook D 16, артикул производителя 53013YDL. Во всех прогонах сценарий продавца одинаковый: родитель выбирает ноутбук к первому видеоуроку. Ниже зафиксированы фрагменты для воспроизводимого теста на 5 ноября 2026 года.

| Предложение | Что передаём в мастерскую | Что проверяем |
|---|---|---|
| ОНЛАЙНТРЕЙД.РУ — снимки в папке исследования | В профиле значение «без ОС» и источник «заголовок предложения». Описание оставляем пустым. | Отчёт должен указать, что описание не передано. По пустому полю нельзя заключить, что продавец нигде не объяснил подготовку к уроку. |
| Lite Mobile | В заголовке предложения указано noOS. В текстовом блоке характеристик есть строка «Операционная система: без ОС». Для теста передаём только эту строку в описание, значение и источник — в профиль. [Карточка продавца](https://lite-mobile.ru/noutbuk-huawei-matebook-d-16-core-i5-13420h-16gb-ssd512gb-intel-uhd-graphics-16-ips-1920x1200-noos-grey-space-53013ydl) | В этом фрагменте указана комплектация. Инструкция, что сделать покупателю, отсутствует. Вывод ограничен переданным текстом. |
| iQ | В характеристиках указано «Без ОС», а в описании встречается «с предустановленной ОС Windows 11». Эти два фрагмента вводятся раздельно. [Карточка продавца](https://novoros.indexiq.ru/product/huawei-matebook-d-16-space-grey-53013ydl-mclg-x-eac/) | Приоритет — проверить противоречие по артикулу. До уточнения в текст макета нельзя включать ни обещание Windows, ни инструкцию, основанную на отсутствии системы. |

**Повторная проверка.** Для случая Lite Mobile приложите новую версию с подписью на втором слайде «Операционная система не установлена. Перед первым занятием её нужно установить». Откройте сравнение версий. Проверьте, что основанием теперь указан второй слайд и что замечание не приписано заголовку. Это контрольная редактура для теста, продавец её не публиковал.

**Для разметки психологом.** Для каждого вывода запишите: с каким наблюдением согласны, что пропущено или ошибочно, на какую область изображения или фразу опираетесь. Ответы покупателей о первом запуске собираются по бланку ведущего отдельно. Эти технические кейсы не измеряют понимание или продажи.
